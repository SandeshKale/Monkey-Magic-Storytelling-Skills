# Glossary

Keep these English keys stable in every language pack. Translate the gloss, not the key.

| Key | Gloss |
|---|---|
| Story | A telling in which the character's mindset or belief system changes. Not a list of events. |
| Anecdote | An incident with no inner change. Most failed daily vlogs are anecdotes. |
| Change | The difference between who the character is at frame one and who they are at the cut. Required. |
| Drama | A character placed in a situation they do not belong in. Comfort-zone violation. |
| Conflict | A problem that stands between the character and the goal. Can be a person, system, object, weather, parent, self. |
| Goal | What the character is trying to reach inside this video. Must be spoken or shown early. |
| Stakes | What they lose if they fail. Triple tax in Lagaan. No helmet after the crash. |
| Protagonist | Main character. On YouTube this is usually the creator. Can also be an object treated as a character. |
| Antagonist | The force opposing the goal. Stronger antagonist makes a stronger hero. |
| Plot | Physical events around the character. Necessary, not sufficient. |
| Character | The person the audience attaches to. On YouTube, the reason people click the next video. |
| 70/30 | Spend 70 percent of craft on character, 30 percent on the idea. |
| Vulnerability | A real shortcoming shown on camera. Fake vulnerability kills the story. |
| Character arc | The character does not end where they started. |
| Idle world | Equilibrium before the inciting incident. One sentence on YouTube, not a first act. |
| Inciting incident | The event that breaks equilibrium and starts the video. |
| Point of no return | The decision after which going home is no longer an option. |
| Climax | Peak emotion, do-or-die. On YouTube this is often the last third, then cut. |
| Resolution | Visible change. Then stop. Do not narrate the ride home. |
| Why / Y | The personal motive for making this video, spoken in the opening. Not "for views." |
| Rasa / Navras | Nine classical performance emotions from the Natyashastra. A video needs several, not one. |
| EEI | Entertainment + Education + Inspiration. A standout video mixes at least two, ideally three. |
| Idea-based video | Premise does the clicking (world's longest train, $1 vs $1M). |
| Personalized vlog | Character does the clicking. Works only while real drama exists in the life. |
| Hybrid | Opens on an idea, lands on the person. Preferred default. |
| CTR | Click-through rate from impression to view. Title + thumbnail job. |
| Retention | How much of the video a clicker watches. Structure + drama + truth job. |
| Engagement | Comments, likes, replies. Algorithm reads this as "people cared." |
| Hook | First 3–30 seconds that stop the scroll or the suggested-video bounce. |
| Object-as-character | An iPhone in a dustbin, a poor man in a five-star hotel. Mismatch creates drama without a human villain. |
| Truth | The non-negotiable. Structure without truth does not connect. |
