# 12 The most important thing

Truth.

Structure, drama, rasa, titles — all secondary. If the content is not true, people do not attach. If the creator performs a self they are not, people leave.

## Rules

- Do not fake the cry, the fight, the bill, the brother, the poverty, the skill.
- Show the shortcoming you actually have.
- Repetitive honest acts (the same run, the same push-ups) can connect. Decorated lies cannot.
- Silence can work when it is true. A quiet river walk with nothing "happening" still holds if the vow is real.
- Implausible plots (villagers beating an empire at a game they just learned) are believed when the emotion underneath is believed.

## Honesty pass on every draft

1. Which line would be false if a neighbour watched?
2. Which emotion is performed rather than felt?
3. Which stake exists only for the camera?
4. What is the creator unwilling to show, and did we respect that?
5. Which number, name, place, or quote has no ledger id?
6. Which claim needs a disclosure (paid, generated, reenacted)?

If (1), (2), (3), or (5) fires, rewrite or replace it with a `GAP`. If (4) was violated, delete that beat. If (6) fires, add it to Open items. See provenance-and-inputs.

## Script rule

When in doubt, cut the clever structure and keep the true sentence.
