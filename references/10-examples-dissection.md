# 10 Dissection method

Use this when the user wants to copy a format or when you need to repair a weak draft. Never copy another creator's life.

## Method

1. Write the opening line. Does it state a problem, a mismatch, or a history — or does it announce a product?
2. Find the character. Person, family, or object-as-character.
3. Find Y. If missing, the video is a demo.
4. List conflicts in order.
5. Mark rasa shifts.
6. Mark the change in the last 90 seconds.
7. Note one unique voice tic worth keeping (a phrase, a humour register). Do not add "Punjabi shock" to a person who is not that person.

## Patterns that worked in the course examples

- Personal problem first, product second. "My PG Wi-Fi dies in this room. Will this cheap extender hold?" then the test, then a blunt fail or win sound.
- History before flex. Tesla was the fastest car — then the new one has to beat that sentence.
- Personal bill as plot. "I have paid zero electricity for a year" is a story opening. "Tesla Solar Roof review" is a label.
- Object in the wrong place. Phone in a bin. Car that cannot swallow the luggage.
- Quiet vlog lifted by an arc. A ration-shop stop becomes a family lunch. The fix is to plant loneliness or hunger at the start so the lunch is a change, not a tour.

## Repair moves

| Symptom | Move |
|---|---|
| Feature list | Open on the user's actual pain |
| Flex opening | Put the product in a place it should not be |
| Tour vlog | Plant a start belief, land on a different belief |
| Clone challenge | Add this creator's Y and one uncopyable particular |
| Long MKBHD-style cold open on a small channel | Shorten. Small channels cannot afford a two-minute history lesson |

## Script rule

When asked to "make it like X," steal the pattern in the table, not the sentences.
