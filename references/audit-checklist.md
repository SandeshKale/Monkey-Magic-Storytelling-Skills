# Audit checklist

Fail the draft if any box is unchecked.

## Story

- [ ] Start belief and end belief are different
- [ ] The change is visible, not only narrated
- [ ] This is not a routine with music

## Drama and conflict

- [ ] The character is in at least one room they do not belong in
- [ ] A named antagonist (person, system, object, body, self) blocks a named goal
- [ ] Stakes are human, not "the algorithm"
- [ ] At least three conflicts in long-form, one in a Short

## Character

- [ ] Swapping the creator for a stranger would break the script
- [ ] One true vulnerability, not performed
- [ ] 70/30 leans character, not premise lecture

## YouTube shape

- [ ] First 30 seconds contain hook + why or inciting incident
- [ ] No cupboard-under-the-stairs world-building
- [ ] Ending cuts at payoff
- [ ] Title is idea-first and payable
- [ ] Thumbnail is one mismatch, not five promises

## Rasa and EEI

- [ ] At least four rasas tagged on a long-form beat sheet
- [ ] Not one emotion for the whole runtime
- [ ] At least two of entertainment, education, inspiration

## Shorts only

- [ ] Question in frame one, answer in the last seconds
- [ ] Progressive reveal
- [ ] Sibling of the long-form, not a new persona
- [ ] No trauma dumped into 30 seconds unless the channel already lives there

## Truth

- [ ] No invented relatives, bills, crashes, tears
- [ ] No line a neighbour could call a lie
- [ ] Forbidden list respected for video models

## Localization

- [ ] Keys preserved
- [ ] Titles still concrete
- [ ] Cultural examples swapped for local ones that do the same job
